# Self-hosted fonts

Latin subsets, identical files and unicode-range to what Google Fonts served
(fetched 2026-10-01, Inter v20 variable, Space Mono v17). Declared in
`src/index.css`; only the Inter file is preloaded (`index.html`).

- `inter-latin-var.woff2` — Inter (weights 100–900, variable). SIL Open Font License 1.1, https://github.com/rsms/inter
- `space-mono-latin-400.woff2`, `space-mono-latin-700.woff2` — Space Mono. SIL Open Font License 1.1, https://github.com/googlefonts/spacemono
